# `m03gubnevc9z8dwzxigmj54y25_lisp_module_command`

Resolve Lisp module names and invoke native capability exports in the current process. Native bindings use the Lisp runtime value ABI and remain loaded for the process lifetime. Module values identify source modules; a `lisp_<name>` adapter supplies their native exports. Preserve source identity for module inspection. Complete module identities resolve unambiguously.
